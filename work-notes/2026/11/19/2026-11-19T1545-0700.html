Working notes: 2026-11-19: the merge-a-thon, a crash, 64-bit SInt, and the oracles become Hazel activities

Claude, 15:45 MST on 11-19, from two sessions: the morning's, which ended when the laptop crashed at 11:32, and the afternoon's, which picked up from it. Picks up from the 11-18 note.

In short

The morning prepared the Hazel team's merge-a-thon and its review of hazeljs; the afternoon answered the reviews and turned the ancient oracles into a site of their own.

  • ^report(58), What Could Merge Today, sorted our open PRs by what each needs; four were brought up to dev and made green (^ticket(772)).
  • Hazel ships no copy of Helvetica Neue, and IBM Plex Sans takes its place (#2837, ^report(59), ^ticket(778)).
  • SInt has 64 bits, not 32, in the interpreter (#2828) and in hazel-jit's compiled code (#2817); overflow stays an error (^ticket(758)).
  • Matt Keenan's review of #2606 is answered: the worker's request carries no cache, and the comments say only what the code does (^ticket(779)).
  • #2818's frame-rate HUD is off by default, and a Flags configuration slide turns it on (^ticket(780)).
  • Hazel was audited for running offline, as a desktop app: only Google's Material Icons and the AI assistant needed a network; #2842 ships the icons (^ticket(774)).
  • The oracles work with no connection, each as an app with its own icon (^ticket(775)), and moved to Hazel activities, the repository renamed hazeljs-examples (^ticket(776)). Solitaire is next (^ticket(782)).

Everything loads from the build but Material Icons (Google Fonts) and the AI assistant (openrouter.ai); a page opened as a file cannot start (module script, worker). #2842 ships the icon font, byte for byte the file Google serves (Apache 2.0); its preview makes no request to Google.
  • ^ticket(779), #2606's review. The request lost prev and use_held_prev; the worker finds its kept cache by document and key. The comments were cut to what the code needs, the description to what the PR does, and both of Matt Keenan's threads answered. Cyrus merged dev into it twice; CI green.
  • ^ticket(758), 64-bit SInt. #2828: an SInt holds a Bigint, checked to [-2^63, 2^63 - 1] after every operation; a power of 64 or more is not computed. #2817 (fast-forwarded to 569d0f186c on Matthew's "Yes, merge it"): an SInt is held as an Int is, a JS number while it is a safe integer and a BigInt past that, the bound checked only on the BigInt path; in Node that costs what the 32-bit check did below 2^53. Full tests green, 4969 and 6996.
  • ^ticket(780), #2818's HUD. Off by default; a third configuration slide, Flags, holds (hud = false) in a checkbox; saved, it applies at startup in every mode. Checked on the preview; CI green.
  • ^ticket(775), the oracles offline. 0.0.24: a service worker, a manifest and an icon per app (a gold hexagram, two fanned cards with a star, a zodiac wheel), install steps under ⚙️ Advanced, and one button that casts the whole reading in full screen. Checked with the local server stopped, and live.
  • ^ticket(776), Hazel activities. 0.0.25: the repository is matthewhammer/hazeljs-examples, the site /hazeljs-examples/ in two parts, ancient oracles and one-player games; the old address sends each page on and retires the old offline worker; matthewhammer.org/hazel/ lists each activity behind its thumbnail.
